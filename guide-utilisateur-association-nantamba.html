1Présentation du site

Ce que propose le site officiel de l'Association Nantamba (AN) et comment il est organisé.

2Démarrage rapide

Les gestes de base pour naviguer, sur téléphone comme sur ordinateur.

  1. Ouvrez https://associationnantamba.org dans votre navigateur (Chrome, Safari, Firefox…). Le site est conçu pour téléphone : il peut aussi être ajouté à l'écran d'accueil (application web « Nantamba »).
  2. Utilisez le bouton ☰ en haut à droite pour ouvrir le menu. Il contient : Accueil, Nos réalisations, À propos, Adhésion, Espace membre, Espace Administrateur, Bénévoles & donateurs, Devenir bénévole, Contact, FAQ, Actualités.
  3. Sur les pages secondaires, le lien ← Retour au site ramène à l'accueil.
  4. Au premier passage, un bandeau de cookies apparaît : choisissez Accepter ou Refuser. Refuser peut limiter l'accès à l'espace membre.
Astuce
Gardez à portée de main votre numéro de téléphone et, pour un paiement, l'application Orange Money : plusieurs démarches (adhésion, don) se terminent par un paiement suivi d'une preuve envoyée sur WhatsApp.

4Devenir membre (adhésion)

Page « Adhésion » : de la demande à la réception du code d'accès.

Pourquoi adhérer ?

  • Prendre part aux activités et projets
  • Accéder à l'espace membre
  • Contribuer aux décisions de l'association

Conditions d'adhésion

  • Accepter le statut et le règlement intérieur de l'association
  • Être guinéen ou sympathisant de la Guinée
  • Payer son droit d'adhésion : 30 000 GNF
Figure 3 — Parcours d'adhésion, de la demande au code d'accès

Pas à pas

  1. Ouvrez la page Adhésion depuis le menu.
  2. Remplissez le formulaire : Nom complet, Activité, Téléphone, Ville.
  3. Cochez « J'accepte le statut et règlement intérieur de l'association Nantamba ».
  4. Cliquez sur Envoyer ma demande d'adhésion.
  5. Dans la fenêtre « Demande envoyée ! », envoyez 30 000 GNF par Orange Money au numéro affiché (224 622 65 86 96, bouton « Copier »).
  6. Faites une capture d'écran de la confirmation de paiement.
  7. Envoyez cette capture par WhatsApp au même numéro avec le bouton Envoyer la preuve par WhatsApp.
  8. Une fois l'adhésion validée, votre code d'accès membre vous est transmis par WhatsApp.
Important
La demande seule ne suffit pas : l'inscription n'est finalisée qu'après réception et vérification de votre preuve de paiement.

5Faire un don

Soutenir les actions de l'association, avec ou sans espace personnel.

Figure 4 — Parcours d'un premier don
  1. Cliquez sur le bouton Faire un don, en haut de la page d'accueil.
  2. Renseignez Nom complet, Numéro de téléphone et Montant du don (GNF).
  3. Cliquez sur Envoyer ma demande de don à AN.
  4. La fenêtre « Merci pour votre générosité ! » affiche le montant et le numéro Orange Money (224 622 65 86 96). Envoyez le montant.
  5. Faites une capture d'écran de la confirmation, puis envoyez-la via Envoyer la preuve par WhatsApp.
  6. L'association confirme la réception et vous remet, après activation, un code d'accès donateur (AND-…).
Bon à savoir
Un donateur dispose d'un seul espace et d'un seul code. Ses dons successifs y sont regroupés. Les dons suivants peuvent être faits directement depuis son espace personnel (voir section 8).

6Devenir bénévole

Offrir du temps et des compétences (santé, éducation, logistique, communication…).

Figure 5 — Parcours du bénévole

  2. Remplissez : Nom complet, Numéro de téléphone, E-mail (facultatif), Vos compétences, Vos disponibilités.

  4. L'association vous recontacte selon ses besoins. Si votre candidature est retenue, un code ANB-… vous est transmis pour accéder à votre espace bénévole.

7L'espace membre

Un espace réservé aux membres, accessible avec le code d'accès reçu après l'adhésion.

Se connecter

  1. Menu ☰ → Espace membre.
  2. Cliquez sur Se connecter : une fenêtre de connexion sécurisée s'ouvre.
  3. Saisissez votre code d'accès puis validez. En cas d'erreur : « Code d'accès invalide. Veuillez réessayer. »
  4. Pour quitter, cliquez sur Se déconnecter.

8Espace bénévole & donateur

Un espace personnel pour celles et ceux qui donnent de leur temps ou de leurs moyens.

Page : menu ☰ → Bénévoles & donateurs. Elle comporte deux blocs de connexion distincts. Saisissez votre code dans le bon bloc.

Espace bénévole
Code de type ANB-KOSO57

Contenu : profil, carte de bénévolat à télécharger, documents publiés, missions & satisfecits, messages de l'association.
Espace donateur
Code de type AND-KOSO57

Contenu : profil, satisfecit global ou par don, liste « Mes dons », nouveau don, messages et informations.

Bénévole : missions et satisfecits

Quand l'association coche une mission accomplie, le satisfecit correspondant se débloque automatiquement dans « Mes missions & satisfecits », téléchargeable avec votre nom, la mission et la date.

Donateur : refaire un don depuis son espace

  1. Connectez-vous avec votre code AND-….
  2. Descendez jusqu'à Faire un nouveau don.
  3. Indiquez le montant (GNF) et, si vous le souhaitez, un message.
  4. Cliquez sur Envoyer ma demande de don. Une fois validé par l'association, le don s'ajoute à « Mes dons » et au cumul de votre satisfecit.
Pas encore de code ?
Bénévole : postulez depuis « Devenir bénévole ». Donateur : le code vous est transmis par l'association après votre don.

9L'espace administrateur

Réservé aux administrateurs : gérer les membres, les finances, le bénévolat et les contenus du site.

Connexion

  1. Menu ☰ → Espace Administrateur → Se connecter.
  2. Saisissez vos identifiants. En cas d'oubli, utilisez Mot de passe oublié ?.
  3. Le Tableau de bord s'ouvre avec 15 onglets. Utilisez Se déconnecter en fin de session.
Sécurité
Ne communiquez jamais vos identifiants. Déconnectez-vous après usage, surtout sur un appareil partagé. Un code d'accès n'est à transmettre qu'une seule fois à la personne concernée.

Gérer les membres

  1. Liste générale : saisissez Nom complet, Date d'adhésion, Téléphone, Ville, puis + Ajouter. Cette liste alimente tous les autres onglets.
  2. Pour reprendre d'anciens membres, utilisez l'Import en masse : un membre par ligne, champs séparés par « ; » au format Nom complet;Date (JJ/MM/AAAA);Téléphone;Ville. Seul le nom est obligatoire (ex. Mamadou Diallo;;;Conakry). Cliquez sur Importer les membres.
  3. Suivi cotisation : filtrez par année d'échéance ou par statut (En retard, À jour, À renouveler, Non renseigné) et exportez en Excel.
  4. Liste et fonction des membres : renseignez fonction et e-mail ; cochez « Bureau exécutif » pour suivre les mandats de 2 ans (début, mandats exécutés, jours restants calculés automatiquement).
  5. Demandes d'adhésion : consultez les demandes reçues et mettez à jour leur statut une fois le paiement vérifié.

Délivrer un code d'accès

Figure 7 — Cycle de vie d'un code d'accès
  1. Membre : onglet « Création de code d'accès » → choisir le membre → Générer un code. Le tableau affiche le code, à qui il est attribué, la date et le statut.
  2. Bénévole ou donateur : onglets « Bénévoles » ou « Demandes de don » → Activer l'espace.
  3. Transmettez le code à la personne (par exemple via WhatsApp), une seule fois.

Gérer les dons et les bénévoles

  • Demandes de don : les dons d'un même donateur sont regroupés sur une ligne. Les dons faits depuis son espace portent le badge « Depuis son espace ». Un don arrivé par le bouton public se rattache avec Rattacher…. Marquer un don « traité » l'ajoute au cumul du satisfecit.
  • Message aux donateurs / aux bénévoles : saisissez un titre et un texte, puis Publier le message.
  • Bénévoles : consultez compétences et disponibilités, activez l'espace.
  • Missions bénévoles : cochez une mission accomplie pour débloquer le satisfecit ; décocher le retire.

Gérer la trésorerie

Figure 8 — Formule du solde final
  1. Solde initial : saisissez le montant de départ et cliquez sur Enregistrer le solde initial (daté et signé de votre nom).
  2. Recettes : libellé, type (Cotisation, Don, Autre recette), date, montant (GNF), puis Ajouter la recette.
  3. Dépenses : libellé, date, montant, puis Ajouter la dépense. Elle reste « en attente ».
  4. Le président approuve ou refuse la dépense (colonne Décision). Seules les dépenses approuvées diminuent le solde.
  5. Consultez les graphiques, puis utilisez Export comptable (Bilan + Grand livre) si besoin.

Statistiques et corbeille

  • Statistiques de visite : visites totales, du jour, sur 7 jours, courbe des 14 derniers jours, visites par page (Accueil, Devenir bénévole).
  • Corbeille : tout élément supprimé (membre, bénévole, donateur, document, certificat, annonce, message, actualité) y est conservé 30 jours et peut être restauré, puis il est effacé automatiquement.
Avant de supprimer
Supprimer un document ou un certificat le retire aussi de l'espace membre. Vous pouvez le restaurer depuis la Corbeille pendant 30 jours.
