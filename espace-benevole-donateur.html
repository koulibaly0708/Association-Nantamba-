Espaces personnels

Espace bénévole & donateur

Un espace dédié à celles et ceux qui donnent de leur temps ou de leurs moyens à l'Association Nantamba. Connectez-vous avec le code d'accès qui vous a été transmis pour retrouver votre profil, vos documents, vos messages et vos justificatifs.

Espace bénévole

Retrouvez votre espace personnel

Si vous avez déjà posé votre candidature via la page « Devenir bénévole » et que l'association a activé votre accès, connectez-vous avec le code qui vous a été transmis.

  • Votre profil et vos informations de bénévole
  • Les documents publiés par l'association
  • Les messages qui vous sont destinés

Espace donateur

Retrouvez votre espace personnel

Si vous avez déjà fait un don via le bouton « Faire un don » du site et que l'association a activé votre accès, connectez-vous avec le code qui vous a été transmis.

  • Votre profil de donateur
  • Votre satisfecit à télécharger
  • Les messages et informations qui vous sont destinés

Faire un nouveau don

Vous souhaitez soutenir à nouveau l'association ? Envoyez votre demande directement depuis votre espace, sans repasser par « Devenir bénévole ».

Votre demande sera examinée par l'association. Une fois le don validé, il s'ajoutera à cet espace, avec votre code d'accès habituel.
